AThe files the app reads and writes

CytogeneticsPro runs in the browser and sends nothing to any server: every file comes in from your computer and goes out to the downloads folder. The app does not save the project by itself: if you close the tab without saving it, the work of that session is lost.

A.1 · What the app reads

WhatWhere and extensionHow it reads it
ProjectOpen a project (home page, Block 2, Ctrl + O) · .jsonA file written by the app, with "app": "CytogeneticsPro"; any other JSON is rejected. It replaces the open project and recomputes everything.
ImagesBlock 2 · .png, .jpg, .jpegSeveral at once; each image is a new cell of the chosen accession (or of a new one). It warns if one is over 25 MB. They are saved inside the project.
MeasurementsBlock 2, Paste measurements · pasted textOne row per chromosome, in microns; columns by name or by number (below). The measurements CSV the block itself writes comes back in whole, with its taxon and its unit.
Record tablesBlocks 5 to 8, Import CSV or pasting over the tableA CSV with headers: each header is matched against the keys, the Spanish and English names and the aliases of the columns, ignoring accents, capitals and symbols. A block copied from a spreadsheet is pasted over the active cell and adds the rows it needs.
Pollen fertilityBlock 5 · .csvThe CSV of PalynoPro, the palynology app of the suite, with the columns landrace_code, n_granos_completos and pct_atipico; the inviable grains are computed as n × % / 100, rounded.
Cytometer histogramBlock 6 · .csv, .tsv, .txtTwo columns (channel, number of nuclei) or one column of event values, which the app bins into 512 classes; with or without a header.
TreeBlock 8 · .nwk, .newick, .tre, .tree, .txt, or pastedNewick, with names in single quotes and branch lengths (ignored by the parsimony); comments in square brackets are removed. From a NEXUS file it takes the first tree of the TREES block. The tips are matched by name with the accessions and taxa.

How texts are read

  • Separator. It is guessed from the first line with text: if it has a tab, tab; if not, if it has a semicolon, semicolon; otherwise, comma. Quoted fields are respected, and a byte order mark at the start is ignored.
  • Decimals. Both the decimal point and the decimal comma are accepted (2,35 is read as 2.35). With a decimal comma, separate the columns with semicolons or tabs, which is what spreadsheets in Spanish write.
  • Empty lines. They are skipped.

The columns of “Paste measurements”

If the first line has some text that is not a number and the p and q columns are recognized in it, it is taken as a header. The names it recognizes (at the start of the header, ignoring capitals):

ColumnHeaders that name it
Accessionacc, accesión, accession, muestra, sample, población, population
Taxontaxón, taxon, especie, species
Cellcél…, cell, placa, plate, metafase, metaphase
Chromosomecrom…, chrom…, núm…, no., #, id
Short arm (p)p, s, corto, short, brazo corto, short arm
Long arm (q)q, l, largo, long, brazo largo, long arm
Satellitesatélite, satellite, sat
Satellite armbrazo…sat, sat…brazo or sat…arm, arm, brazo
Unitunidad, unit

Without a header, the columns are read by their number: 2 columns, p q (a new cell); 3, chromosome p q; 4, cell chromosome p q; 5 to 7, accession cell chromosome p q [satellite] [arm]. A row without a valid number for p (≥ 0) and for q (> 0) is skipped, and the message says which. A satellite goes on the q arm if the arm column says q, l, largo or long; otherwise, on p. Accessions that do not exist are created with the name the column brings; if the table has a taxon but no accession, one accession is created per taxon, and the taxon is written into the accession. Rows with neither accession nor taxon go to the chosen accession, and a new one is created only if needed: pasting a table that names its accessions does not leave an empty “Accession 1” behind. A cell whose unit column says px (an uncalibrated cell exported earlier) stays in pixels, and the message warns about it: “One cell comes in pixels (not calibrated).”

So the measurements.csv file written by Block 2 (accession, taxon, cell, chromosome, p, q, satellite, satellite arm, unit, source) can be pasted back without losing anything; the source column is ignored.

accession;cell;chromosome;p;q;satellite;arm

Huatusco;C1;2;1,35;1,52;;

iWhat the browser remembers

The browser keeps only preferences, not data: the interface language, the light or dark theme, the animations and the edits made with the editor ✎. To keep an analysis, save the project.

BThe rules, gathered

The rules the app applies to classify, warn or decide, with the block where they act. They are the same ones each chapter explains; here they are together to look up at a glance.

B.1 · Chromosome classification (Block 3)

SchemeClasses and limits
Levan et al. (1964), by arm ratio r = q / p (the default)m: r ≤ 1.70 · sm: 1.70 < r ≤ 3.00 · st: 3.00 < r ≤ 7.00 · t: r > 7.00. A value exactly on the limit goes to the more median class (r = 1.70 is m; r = 3.00 is sm).
Levan et al. (1964), by centromeric index CI = 100 p / (p + q)m: CI ≥ 37.5 · sm: 25–37.5 · st: 12.5–25 · t: < 12.5, with the same convention.
Guerra (1986)m: 1.00–1.49 · sm: 1.50–2.99 · a (acrocentric): ≥ 3.00. The limit goes to the upper class (r = 1.50 is sm; r = 3.00 is a).
Own limitsThe r limits you type and one more name than limits.
M and T checkboxM only with exactly equal arms (r = 1); T, with no short arm (p = 0).
  • Satellite. Its length is added to that of the arm where it sits; the pair is marked “-sat”.
  • Fundamental number (NF). Two arms per m and sm chromosome; one per st, a and t, unless you choose to count st with two.
  • Variation warning. A pair whose length varies by more than 20% among cells (coefficient of variation) is flagged: it may be different condensation or a mispaired homolog.

B.2 · Asymmetry (Block 4)

Recommended indices ★MCA and CVCI (intrachromosomal) and CVCL (interchromosomal), as recommended by Peruzzi and Eroğlu (2013). The others (TF%, AsK%, Syi, Rec, A1, A2, A, AI, DI) are given to compare with earlier work.
Stebbins categories (1971)The letter by the ratio of the longest to the shortest chromosome: A < 2; B from 2 to 4 (both ends included); C > 4. The number by the proportion of chromosomes with r below 2: 1 if all; 2 from 0.99 to 0.51; 3 from 0.50 to 0.01; 4 if none.
Standard deviationSample (n − 1) by default in CVCL, CVCI and A2; it can be changed to population (n).
Undefined CVCIIf every chromosome is telocentric (0/0), not zero.
DIWith the medians of the short arm and of the length (Lavania and Srivastava 1992).

B.3 · Meiosis (Block 5)

Autopolyploid or allopolyploid?A hypothesis fits if the χ² test of the observed against the expected configurations gives p ≥ 0.05; classes with fewer than 5 expected are merged with their neighbor. A formula that does not allow some observed configuration (multivalents where only bivalents fit) is rejected without a test. Up to three formulas and eight genomes.
Meiotic index (Love 1951)Normal tetrads / all × 100; ≥ 90 is read as a stable meiosis.
Pollen viabilityProportion of viable grains with the Wilson and Clopper–Pearson intervals; if the homogeneity test among plants gives p < 0.05, it is better to report them separately.

B.4 · Ploidy and genome size (Block 6)

Chromosome numberThe mode of the counted cells; with more than one mode, the app asks you to count more cells. If the mode is not a multiple of x, it warns: aneuploidy, B chromosomes or dysploidy.
Flow cytometry2C = (G1 channel of the sample / G1 channel of the standard) × 2C of the standard; 1C = 2C / 2; 1Cx = 2C / ploidy level; 1 pg = 978 Mbp.
Peak qualityIt warns if some peak has a CV above 5%, if the sample / standard ratio is between 0.85 and 1.18 (the peaks overlap) or if it is above 3 or below 1/3 (the cytometer response may stop being linear).
Allium testEach treatment is compared with the control, with the Holm correction; a mitotic index below half that of the control is a strong sign of cytotoxicity.

B.5 · Banding and FISH (Block 7)

  • Position on the arm, from the centromere (0) to the telomere (1): proximal < 1/3; interstitial from 1/3 to 0.8; terminal > 0.8.
  • Sites per set. A site on both homologs counts one; on only one, half (and it is counted as a heteromorphism), with the same criterion in the pattern of the accession and its regions, in the table of all accessions and in the comparison matrix.

B.6 · Comparison among taxa (Block 8)

  • Minimums. At least one variable and three accessions or taxa with data; the component analysis needs at least two variables that vary.
  • Incomplete rows. By default, Left out (only rows with every variable): only the rows with every chosen variable enter the clustering and the components; the others stay in the matrix, in the number tree and on the map, and the app says which are left out and what they lack. All, with the variables every row has uses only the common variables. All; each pair with the variables it shares computes the Gower or the Euclidean distance (rescaled to the total) with what each pair shares; it warns if some pair shares half the variables or fewer, and stops if one shares none. The components put empty cells at the mean.
  • Ward works with squared distances and gives the heights on the scale of the distance.
  • Evolution of the number. Sankoff parsimony with the costs of +1, −1, ×2 and ×1.5 that you choose (1, 1, 1 and 1.5 on opening); an odd 2n does not enter the analysis; at least two tips with a number are needed, and the others are treated as unknown.

B.7 · Teaching (Block 9)

  • Karyotype exercise. Arm ratios far from the Levan limits (m 1.10–1.45, sm 2.0–2.6, st 3.8–5.5); each pair 20 to 25% shorter than the one before.
  • Self-assessment. The right-answers box turns to a warning color below 70%.

All of them are guides for reading the results, not laws: what you know about your material, the preparation and how it was measured always comes first.

DWhen something does not work

The messages of the app, as they appear in the English interface, with what they usually mean and what to do. The ellipses are the part of the message that changes (a name, a number).

MessageWhat is happening and what to do
Projects and files
“Could not open the project: The file is not a CytogeneticsPro project.”The JSON is from another app or is not a project. Open a .cytogeneticspro.json saved by the app.
“Only PNG or JPG images and .json projects can be opened.”The file is of another type (TIFF, PDF…). Convert it to PNG or JPG.
“Could not read the image …”The file is damaged or is not the image its extension says.
“The image … is over 25 MB: the project will be heavy.”Only a warning; if the project becomes slow, reduce the image.
“No row had two valid numbers for p and q.”The columns were not recognized or contain text; check the header or the separator (Appendix A.1).
“The file had no recognizable columns.”No header of the CSV matches a column of the table; use the names the table carries when exported.
Measurement and karyotype (Blocks 2 and 3)
“… has one uncalibrated cell: their measurements are in pixels.” (or “… uncalibrated cells…”)Calibrate with the scale bar (or type the measurements in microns) to mix them with the others.
“One cell comes in pixels (not calibrated).” (when pasting measurements)The unit column said px; the cell stays in pixels until you calibrate it or type its measurements in microns.
“In … not every cell has the same number of measured chromosomes (mode …).”Some chromosome is missing or duplicated in some cell; Block 3 groups whatever there is.
“This accession mixes calibrated cells (µm) and uncalibrated ones (pixels).”Relative lengths hold; absolute ones do not. Calibrate them all in Block 2.
“The cells do not have the same number of chromosomes (…).”Check the pairing of the incomplete cells.
“With … chromosomes and … homologs per group one group is incomplete.”The number of homologs per group does not divide 2n; check that setting or the counts.
“Pairs … vary by more than 20 % among cells.”Different condensation or a mispaired homolog; look at the relative length.
“There must be one more name than limits.”In own limits, type for example limits “1.7, 3, 7” and names “m, sm, st, t”.
Meiosis, ploidy and bands (Blocks 5 to 7)
“Type the base number x of the accession to set out the hypotheses.”Without x there are no genomic formulas to test.
“Formula … with x = … gives 2n = …, but the cells have ….”The formula does not match the number of the cells; correct it.
“No hypothesis fits (the best: …).” · “More than one hypothesis fits (…): more cells are needed to decide.”Try another formula or record more cells.
“The file lacks the PalynoPro columns (landrace_code, n_granos_completos, pct_atipico).”The CSV does not come from PalynoPro; enter the grains in the table.
“There is more than one mode: count more cells before deciding the number.”Two or more numbers tie; count more.
“The modal number is not a multiple of x = …”Aneuploidy, B chromosomes or a different base number.
“…: some peak has a CV above 5 %.”Repeat the preparation: damaged nuclei or debris.
“…: sample and standard nearly coincide (ratio close to 1).”Choose a standard with a more different content.
“…: sample and standard differ more than threefold in DNA content.”So far apart, the cytometer response may stop being linear: choose a standard closer in size to the sample, without the peaks overlapping.
“No numbers were found in the file.”The cytometer CSV has no numeric columns the app recognizes (Appendix A.1).
“The chosen gates are empty.”Adjust the limits of the histogram gates.
Comparison (Block 8)
“Only the rows with every chosen variable enter the clustering and the PCA. … rows are left out (…), lacking …”It is the default of Incomplete rows. To include them, choose only the variables they have or change that menu.
“Only the variables every row has are used (…); … are left out.” · “None of the chosen variables is in every row.”With All, with the variables every row has; in the second case, choose other variables or another option.
“Some pairs share few variables: “…” and “…” only have … in common (… of …), and their distance, …, comes from those alone.”With All; each pair with the variables it shares: two different karyotypes can end up at distance 0; read the dendrogram with care or change Incomplete rows.

“These pairs share no variable: …”With the pairwise comparison: remove variables or complete the data.

“At least two tips with a number are needed.”The tip names do not match the accessions or taxa, or they lack 2n; type it in Numbers of the tips.
“…: 2n = … is odd; it has no whole haploid number and does not enter the analysis.”That tip is treated as unknown.
“There is no dendrogram yet.”Do the clustering above first.
“The file is not valid GeoJSON.”The file is not JSON or its type is not one the app reads (Appendix A.1).
Figures and report (Block 10)

“Could not copy; use “Download”.”The browser did not allow the clipboard.
“Could not build the package: …”It is usually memory with very large images; close other tabs or download in parts.
✕If the problem is not on the list

Save the project (Ctrl + S), reload the page and open it again: since the results are recomputed from the data, almost any odd state is fixed this way. If it persists, use Report a problem in the top bar, with the steps to repeat it; do not attach images or data you cannot share.

EThe tool: license and how to cite it

E.1 · What it is and what it is not

CytogeneticsPro is written for this program: the statistical distributions, the karyotype, the asymmetry indices, meiosis, the idiogram, the teaching simulators, the report, the .zip file and the illustrations are in its own code, which can be read. It uses no third-party libraries, ships no fonts (it uses the fonts of the computer), has no minified code or build steps, and loads nothing from the network: that is why it opens with a double click and offline. The only outward links, to the suite portal and Report a problem, are followed only if you click them.

It implements published methods, each cited to its original source in the code, on the home page of the app and in the methods Block 10 writes (Appendix F). The four examples are simulated with a script of its own: the names of the species and places are real, the measurements are not. The only third-party element is the line icons drawn by the shared modules of the suite—the navigator, the figure studio and the effects—: they come from the Lucide project, under the ISC license (those derived from the Feather project also carry the MIT license), both permissive and compatible with the GPL. The file LICENSES-TERCEROS.md lists them with the text of their licenses, and PROCEDENCIA.md says where each part of the program comes from.
